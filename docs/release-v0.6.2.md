# srcmv v0.6.2 release notes

This is a patch release with no source changes. Like v0.6.1, it exists to
exercise the `Release train` automation — this time as the first expected
fully automatic, uninterrupted run: tag creation, Release workflow dispatch,
native builds, publication, and the Homebrew tap notification with no manual
recovery in between.

The v0.6.2 archives are built from the same source tree as v0.6.1; the only
difference is the workspace version itself. Upgrading from v0.6.1 is optional
and carries no behavioral change.
