# srcmv v0.6.1 release notes

This is a patch release with no source changes: it exists to exercise the new
`Release train` automation end to end (automatic tagging on version bump, CI
gating, annotated tag creation from these notes, Release workflow dispatch,
and post-publication verification).

The v0.6.1 archives are built from the same source tree as v0.6.0; the only
difference from v0.6.0 is the workspace version itself. Upgrading from v0.6.0
is optional and carries no behavioral change.
